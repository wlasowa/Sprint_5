# Sprint_5

## UI-автотесты для учебного сервиса "Доска"

## Описание проекта:

conftest.py — фикстура driver(): запуск браузера, открытие сайта, закрытие после каждого теста
locators.py — локаторы элементов
data.py - тестовые данные
urls.py - адрес сайта
tests/test_registration.py — тесты регистрации (позитивные, негативные)
tests/test_login.py — вход под существующим аккаунтом
tests/test_logout.py — выход из аккаунта
tests/test_ad.py — размещение объявления (авторизованным и неавторизованным)
